# Safari RBC Agent

Небольшой ИИ-агент на Python, который открывает `https://www.rbc.ru`.

- На macOS агент запускает сайт именно в Safari.
- На других ОС агент открывает сайт в браузере по умолчанию.

## Запуск

```bash
python3 safari_rbc_agent.py
```

## Дополнительно

```bash
python3 safari_rbc_agent.py --url https://www.rbc.ru
```
